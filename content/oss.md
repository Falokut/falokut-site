## Open Source

Контрибьютор [txix-open](https://github.com/txix-open) — набора
Go-библиотек и сервисов для продакшена.

## Проекты

| Проект | Что это |
| --- | --- |
| [isp-kit](https://github.com/txix-open/isp-kit) ★ 14 | Фреймворк для Go-микросервисов: жизненный цикл приложения, конфигурация с hot-reload, PostgreSQL, Kafka / RabbitMQ / STOMP, HTTP и gRPC, OpenTelemetry, Prometheus, Sentry |
| [isp-python-wrapper-kit](https://github.com/txix-open/isp-python-wrapper-kit) | Python-сервисы как часть Go-приложения: PySupervisor, hot-restart при смене конфигурации, healthcheck |
| [etp](https://github.com/txix-open/etp) ★ 15 | Event-транспорт — альтернатива socket.io |
| [grmq](https://github.com/txix-open/grmq) ★ 9 | Обёртка с высокой абстракцией над RabbitMQ |
| [bgjob](https://github.com/txix-open/bgjob) | Tiny-библиотека для фоновых jobs |
| [ispctl](https://github.com/txix-open/ispctl) · [isp-config-service](https://github.com/txix-open/isp-config-service) | Инструменты и сервисы платформы |
